A number with a record behind it

The brand concept includes individually numbered units. A unit number would identify one item within a defined production run; a batch reference would connect it to the relevant production record.

Numbering has not been assigned for this preview. A number alone would not establish ingredient origin, authenticity or limited availability. The final format and supporting records will be published when the production system is confirmed.
